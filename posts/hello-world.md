# 你好，世界

欢迎来到我的个人博客。这是一个用 **静态站点生成器** 构建的站点，所有文章都以 Markdown 书写，简单、纯粹、以阅读为核心。

## 为什么写博客

- 沉淀思考，把模糊的想法写清楚
- 记录技术实践，方便日后回看
- 与同好交流，共同进步

> 写作是最好的思考方式。

## 这个站点能做什么

| 功能 | 说明 |
| --- | --- |
| 文章列表 | 分页展示，按发布时间倒序 |
| 标签筛选 | 一个文章可关联多个标签 |
| 全文搜索 | 按标题与内容关键词检索 |
| 阅读体验 | 响应式、语法高亮、舒适排版 |

## 一段代码示例

```javascript
function greet(name) {
  return `你好，${name}！`;
}
console.log(greet('世界'));
```
